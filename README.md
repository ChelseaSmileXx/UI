## Описание

Это учебный проект — интернет-магазин светильников с динамической загрузкой товаров, фильтрацией и корзиной.

## Функционал

- Динамическая отрисовка карточек товаров из JSON
- Фильтрация по типу светильников и наличию на складе
- Сортировка по цене (дешёвые/дорогие) и популярности
- Пагинация для большого количества товаров
- Корзина с добавлением/удалением и счётчиком
- Анимационный слайдер (Swiper.js)
- Форма обратной связи с валидацией (Just Validate) и отправкой на тестовый сервер
- Аккордеон для FAQ и бургерное меню с выбором города

## Технологии

- HTML5
- CSS3 / SCSS
- JavaScript (ES6+)
- Swiper.js, Just Validate

## Инструкция по запуску

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/ChelseaSmileXx/UI.git
   ```

2. Перейдите в папку проекта:
   ```bash
   cd UI
   ```

3. Откройте файл index.html в браузере (или используйте Live Server в VS Code)
